# Offline media register

Reviewed 17 October 2026. The shared library has 50 educational image records: 8 Commons photographs, 18 official-portal festival covers requested by the user, and 24 original diagrams. Personal Kuwento media is separate and is never promoted into this collection.

Each record contains a precise source URL, creator/rights status, capture-date statement, checked date, description, alternate text, changes, and related record IDs. Card previews may crop visually; the full Koleksyon viewer preserves proportions. No photographer or capture date is inferred from a website name or upload filename.
