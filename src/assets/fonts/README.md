# Noto Sans Hanunoo

`NotoSansHanunoo-Regular.ttf` is bundled for offline rendering of the Hanunó’o Unicode inventory in Sulat Pamana.

- Font family: Noto Sans Hanunoo
- License: SIL Open Font License 1.1
- Source: https://github.com/notofonts/noto-fonts
- Font file source: https://raw.githubusercontent.com/notofonts/noto-fonts/main/unhinted/ttf/NotoSansHanunoo/NotoSansHanunoo-Regular.ttf

The font is used as a rendering asset only. It does not determine language readings, translations, or community usage.

The original learning diagrams also embed the same unmodified font. [OFL.txt](OFL.txt) retains the bundled file’s copyright notice (2017–2021 Google Inc., read from its name table) and the SIL Open Font License 1.1 text from the official Google Fonts distribution. That complete notice is also embedded in each script diagram’s metadata and accessible from its Koleksyon record. No font data is extracted from the Unicode PDF chart.
