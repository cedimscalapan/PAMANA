# SMART PAMANA

Offline-first Ionic Angular application for learning about Oriental Mindoro's culture and heritage.

## Current implementation

- Angular standalone app shell with Ionic components, Capacitor Android packaging, and route-based navigation.
- SMART PAMANA design tokens based on the supplied visual references.
- Four-step onboarding with locally persisted completion state.
- Functional home dashboard with module shortcuts, daily fact rotation, lesson detail flow, and bottom navigation.
- Offline lesson catalog with category filters, source attribution, lesson completion persistence, quest scoring, writing practice, place details, stories, collection state, and reset controls.
- Strict TypeScript configuration and no runtime network dependency in the implemented slice.

## Local development

```text
npm install
npm run build
npm start
```

The Android project is generated by the committed Capacitor workflow. The current offline persistence layer uses device-local storage so the browser build and Android WebView behave consistently; the SQLite migration contract is kept in `src/app/core/database/schema.ts` for the native adapter phase.

## GitHub Actions

The web workflow builds the Angular bundle. The Android workflow builds and uploads the installable `smart-pamana-debug-apk` artifact.


## Android APK

Use GitHub Actions → `Build SMART PAMANA Android APK` → `Run workflow`. After it completes, download the `smart-pamana-debug-apk` artifact, extract `app-debug.apk`, copy it to an Android device, enable installation from unknown sources for the file manager, and open the APK to install it.

## Cultural review note

The supplied mascot board is used as a visual reference only. Cultural clothing, script glyphs, translations, stories, and place facts must be backed by cited sources and, where applicable, community or educator review before release.
